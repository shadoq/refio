## Executive Summary

### Co to jest Refio?

**Refio** to local-first AI coding assistant dla IntelliJ IDEA, napisany w 100% w Kotlin. Oferuje 50-70% niższe koszty API dzięki RAG, 100% lokalną opcję z Ollama, i natywną integrację ze Swing UI.

### Kluczowe USP

1. **50-70% niższe koszty API** - RAG minimalizuje tokeny
2. **100% local-first** - pełne wsparcie offline z Ollama
3. **Natywna integracja IntelliJ** - Swing UI, nie WebView
4. **18 MCP presetów** - rozszerzalność out-of-box
5. **Open source (MIT)** - bez vendor lock-in

### Pozycjonowanie

> "Jedyny AI coding assistant dla IntelliJ IDEA, który oferuje 100% local-first architekturę z 50-70% niższymi kosztami API"

### Grupy docelowe

| Segment | Pain Points | Refio Solution |
|---------|-------------|----------------|
| Enterprise Java/Kotlin | Security, costs, IntelliJ native | Local-first, RAG savings |
| Cost-conscious startups | $20-40/dev/month | Free + API savings |
