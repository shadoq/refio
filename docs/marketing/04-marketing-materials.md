Refio is the only AI coding assistant that combines **native IntelliJ integration** with **100% local data control** and **50-70% lower API costs**.

Let AI execute multi-step tasks with:
- Automatic planning

Create specialized AI assistants with custom prompts and tool access. Built-in security and code review agents included.

## 8. FAQ Content

### 8.1 Marketing FAQ

**Q: Is Refio really free?**
A: Yes. Refio is MIT licensed open-source software. There are no paid tiers, no premium features behind paywalls, and no usage limits.

**Q: How does Refio make money?**
A: Currently, Refio is a passion project. Future monetization may include enterprise support packages, hosted services, or premium MCP integrations - but the core product will always be free.

**Q: What's the catch with "50-70% lower costs"?**
A: No catch. Our RAG system sends only relevant code chunks to the LLM instead of entire files or repositories. Fewer tokens = lower costs. You can verify this in the built-in cost tracking dashboard.

**Q: Can I use Refio without any cloud services?**
A: Yes. With Ollama, Refio works 100% offline. Your code never leaves your machine.

**Q: Is Refio as good as GitHub Copilot?**
A: Refio and Copilot serve different needs. Copilot excels at inline completion across many IDEs. Refio excels at IntelliJ-native workflows with local-first privacy and agent capabilities. Many developers use both.

**Q: Why should I trust an open-source AI tool?**
A: You can read every line of code. You can audit exactly what data is sent where. You can fork and modify for your needs. Transparency builds trust.
