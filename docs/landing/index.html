Execution

Think. Inspect. Execute.

Three modes, one workflow. Choose the level of control you need — from quick answers to full autonomous refactoring.

01

Chat — Think

Ask questions about your code. Dynamic project context, RAG retrieval, rich code citations. No file changes, no tools.

Instant answers Read-only
02

Plan — Inspect

Run read-only analysis with code tools. The model explores your project, builds a step-by-step plan, and waits for your approval. Guaranteed safe.

Safe planning 5 read-only tools
03

Agent — Execute

Automated changes across files. 12 tools, automatic snapshots, and subtask tracking in a turn-based execution loop. Full control — direct edits, always reversible.

Local-first

Designed around local models

Refio works out-of-the-box with local models — no weird config, no cloud tokens. Local models become practical for real IDE workflows.

Local models, done right

  • Works with local Ollama models out of the box
  • Small context windows? Handled with smart compaction
  • Token budgeting, summarization, RAG threshold
  • No accidental data leakage — no-egress mode
  • Cloud adapters available: OpenAI, Anthropic, Gemini, OpenRouter

Context budget

~28K tokens split across 8 configurable sections. System prompt, RAG, conversation, tools — you control the allocation.

RAG pipeline

RAG indexing with local embeddings, cosine similarity search, and 5 language analyzers. All stored in SQLite, fully offline.

Native IntelliJ UX

Kotlin + Swing. No webviews, no wrappers, no slow bridges. Feels like a first-party JetBrains tool.

Get started

Up and running in 3 steps

Works with local models out of the box. No API keys required.

1

Install Ollama & pull models

ollama pull nomic-embed-text ollama pull qwen2.5-coder:7b
2

Install Refio plugin in IntelliJ

Settings → Plugins → Install from disk (or Marketplace when available)

3

Open Refio tool window — pick a mode — go

View → Tool Windows → Refio. Chat, Plan, or Agent.
