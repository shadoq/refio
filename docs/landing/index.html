Local-first AI assistant for IntelliJ

Ship with context, not noise.

Refio is an open-source, Kotlin-native coding companion that keeps data local, streams only what matters, and works inside your IDE without a webview. Tested with local models and smaller cloud-hosted models, it is designed to minimize usage costs by default.

Local-first by design

Your project stays local. No-egress mode, path sandboxing, and on-device embeddings keep privacy under your control.

Context you can trust

RAG + code analysis trims the prompt to only the most relevant snippets. Less token waste, better answers.

Native IntelliJ UX

Built with Kotlin and Swing. No webviews, no wrappers, no slow bridges. It feels like a first-party tool.

Features that feel like tooling, not a chatbot

Refio is designed to minimize context, automate retrieval, and keep full control in the IDE.

RAG indexing

Semantic chunking, embeddings, and SQLite storage for fast, local retrieval.

Context providers

@file, @folder, @codebase, @docs, @grep, @diff, @terminal and more.

MCP integration

Model Context Protocol with STDIO/HTTP transports and preset servers.

Tool system

Read/write tool registry with permissions and safety limits.

Conversation summarization

Reduce token usage by ~50-70% while preserving critical decisions.

Security-first

Path sandboxing, denylist, redaction, and no-egress mode by default.

Three execution modes

Go from quick answers to safe, step-by-step execution without leaving your IDE.

Chat

Instant responses with dynamic project context and rich citations.

Fast Q&A

Plan

Read-only step generation with review and approval.

Safer planning

Agent

Read/write execution with snapshots, rollback, and reflection loops.

Automated workflows

Built for developer workflows

All Kotlin, in-process, with SQLite WAL and modern LLM adapters.

Core stack

  • Kotlin 1.9.25 | JDK 17
  • IntelliJ Platform 2024.1
  • SQLite + Exposed ORM

LLM adapters

  • Ollama, OpenAI, Anthropic, Gemini
  • OpenRouter, LM Studio
  • Streaming + cost tracking

RAG pipeline

  • Language analyzers (Kotlin/Java/Python/TS)
  • Semantic chunking + embeddings
  • Checksum-based indexing
