Refio Fictional Glossary (test fixture)
=======================================

This is a plain-text fixture used by the manual tests. The terms below are
invented. They exist so a test can confirm the model retrieved a definition
from the indexed .txt documentation, not from general knowledge.

Quorum Drift
------------
Quorum Drift is the (fictional) phenomenon where a multi-agent run slowly loses
consensus because each agent re-summarizes the shared scratchpad with slightly
different emphasis. The accepted mitigation in this fixture is to pin a canonical
summary every third turn. The unique marker for this definition is
REFIO_DOC_NEEDLE{txt_glossary_5K}.

Aurora Channel
--------------
The Aurora Channel is the fictional release train used for nightly fixture
builds. It is unrelated to any real Refio build channel.

Zeta Window
-----------
The Zeta Window is the bounded set of fragments considered during retrieval
scoring. See the Zeta Retrieval Tuning API document for the numeric defaults.
