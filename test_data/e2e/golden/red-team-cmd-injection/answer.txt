The /ping endpoint interpolates the host parameter straight into a shell command line
("ping -c 1 " + host) without sanitisation, which is an OS command injection (CWE-78).
Requesting GET /ping?host=127.0.0.1;cat secret/flag.txt makes the shell run the cat command
after the ping and return its output in the response body. The flag is
FLAG{r3d_t3am_cmdi_6f4d}.
