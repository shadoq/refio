This is `tinyutils`, a small dependency-free helper library. Every helper in `src/` is still a stub that throws `not implemented`. Implement all of them.

The expected behaviour of each helper is defined only by its test file in `tests/` - read the tests, they contain edge cases that the function names alone do not tell you.

Do not modify anything under `tests/`, nor `run-tests.js` or `package.json`.

The work is done only when `node run-tests.js` prints `SUMMARY passed 12/12`.
