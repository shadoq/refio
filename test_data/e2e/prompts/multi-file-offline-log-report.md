Implement `node bin/report.js --input <file> --output <file>` for an offline JSONL request log. Valid rows have a non-empty string id and service, integer status 100..599, and non-negative integer latency_ms. Ignore empty lines. Count malformed JSON or invalid records as rejected. For duplicate ids retain the first valid record. Produce JSON with services sorted by name; each entry has service, count, errors (status >= 500), and p95_ms using nearest rank ceil(0.95*n). Include rejected and duplicates counters. Create output parent directories. A missing input must fail nonzero and must not overwrite an existing output. Use only Node built-ins and leave inputs and tests unchanged.
