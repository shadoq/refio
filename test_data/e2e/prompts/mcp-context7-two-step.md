You have access to a documentation service over MCP. It works in two steps: first resolve the
library name to a library ID, then request documentation using that exact ID.

Look up how routing works in the Kotlin library **Ktor**, then write a short note to
`docs-note.md` in the project root containing:

1. the `Retrieval-Token` value from the documentation response, copied exactly, and
2. the library ID you used.

Do not guess the library ID and do not invent the token. Both must come from the service.
