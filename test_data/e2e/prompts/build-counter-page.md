Create a single self-contained file `counter.html` with a simple counter widget.

Requirements:
- An element with `id="count"` that displays a number, starting at `0`.
- A button with `id="inc"` labelled something like "Increment".
- Clicking the button increases the displayed count by 1 each time.

Use plain vanilla HTML and JavaScript in the one file - no external libraries or frameworks,
no network requests. The page must run with no JavaScript errors.
