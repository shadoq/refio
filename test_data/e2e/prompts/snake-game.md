Write a classic Snake game as a single self-contained file `snake.html` (HTML + CSS + JavaScript
inline; no external libraries or assets).

Requirements:
- A 30x30 grid. The snake moves continuously in one of four directions and grows when it eats food.
- The game ends if the snake hits a wall or itself.
- Keyboard controls (arrow keys) for the human player.
- A CPU-controlled snake mode that automatically heads toward the food.
- Three game modes, selectable from a start menu: human vs human, cpu vs human, cpu vs cpu.
- Show the current score during play.
- A start menu and a game over screen, and restart on a keypress.

Put everything in the one file `snake.html`.
