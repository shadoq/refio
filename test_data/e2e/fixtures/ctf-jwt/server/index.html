Notes API (local demo)

  • GET /login?user=alice - issue a session JWT (admin logins are disabled)
  • GET /protected?token=... - verify a token and greet its subject
  • GET /admin?token=... - admin-only area (role=admin required)

Session tokens are JWTs signed with HS256. The signing key is managed by the platform team; see the deployment notes in the project README.
