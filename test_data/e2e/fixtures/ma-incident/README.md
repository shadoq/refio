# web06 - incident response workspace

A stand-in image of `web06`, a small web host that was compromised. The tree mirrors
the filesystem layout of that host (etc/, var/, opt/, home/) and `runbook.md` is the
certified containment procedure. `.refio/agents/` holds the IR team profiles and
`verify.py` is the acceptance gate.

Everything here is local and throwaway: this is an authorised incident-response
exercise, no real system is involved.
