# Mini Shop run

A local catalog shop is running at `http://127.0.0.1:8740` (landing page, `/catalog`
JSON, per-product pages). The buying mission - budget, shopping list, selection rule and
deliverable shape - is fixed in `docs/mission.md`.

- `server/catalog.json` - the catalog the shop serves.
- `docs/mission.md` - the authoritative mission.
- `checks.py` - the acceptance gate (do not modify it).

Write the chosen cart to `cart/cart.json`.
