# test_data - fixtures for the manual tests

Committed fixtures backing **tests 46-58** in
[`docs/manual-tests.md`](../docs/manual-tests.md). They exercise the
documentation-indexing feature (`DocsSettingsPanel` → RAG) and MCP servers
(`MCPSettingsPanel` → `MCPManager`).

Unlike the per-run artifacts under `tmp/refio-manual/` (which must NOT be
committed), everything here is **version-pinned input data** that lives in the
repo so the tests are reproducible on any clone.

## Layout

```
test_data/
  README.md            ← this file
  needles.md           ← canonical list of every needle token + which test asserts it
  docs/                ← local files for "Add Local File" (T46, T47, T50, T51)
    refio-fictional-api.md
    glossary.txt
    datasheet.pdf      ← generated by make_pdf.py (stdlib only)
    make_pdf.py
  docsite/             ← static site for "Add Documentation URL" crawl test (T48)
    index.html  guide/page1.html  guide/page2.html  guide/deep.html  offsite.html
  mcp/                 ← offline MCP stub server (T52-T58)
    stub_server.py  README.md  resources/project-notes.md
```

## Needles (how grading works)

A **needle** is an unverifiable, made-up fact tagged with a unique token (e.g.
`REFIO_DOC_NEEDLE{md_alpha_7Q}`). A model can only reproduce it by actually
retrieving the indexed fixture, so a test PASSes iff the model echoes the exact
token. See [`needles.md`](needles.md) for the full catalog.

## Serving the doc-site (T48)

```bash
# from repo root
python -m http.server 8799 --directory test_data/docsite
# then in IntelliJ: Settings → Documentation → add URL  http://localhost:8799/
```

## Offline vs online

These fixtures are designed for **fully offline** testing (local files, a local
HTTP server for the crawl, a stdio stub MCP server). The *online smoke* test
(T57) is the only one that needs network/npx - it is explicitly optional.

## Prerequisites

- An **embedding model** configured (`ollama/nomic-embed-text` or an OpenAI key);
  documentation retrieval (`@docs`, `rag_search content_type=DOCUMENTATION`)
  needs embeddings.
- **Python** on PATH (for the doc-site server and the MCP stub).
- For tiny corpora the default `rag_search` threshold (0.65) can be slightly
  high; if a needle is not retrieved, lower the threshold or rephrase the query
  before recording a FAIL (note it in the log).
