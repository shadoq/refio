Operator's guide

Try the onboard ROM

Press Run to draw the ship. Move with physical keys Q / E (left / right) and W / S (up / down). Hold R to beep with audio enabled.

The demo is a real 65-byte CHIP-8 program. It erases and redraws its sprite using XOR, pacing movement with the delay timer.

Click the display before using physical keys if a control has focus. The on-screen keypad supports mouse and multitouch.

Machine & compatibility

  • Classic CHIP-8: 4 KB memory, font at 0x050, ROM at 0x200. Local files only; 1–3584 bytes.
  • Modern profile: shifts use Vx; logic preserves VF unless VF is the destination. Transfers leave I unchanged; Bnnn uses V0.
  • Sprites wrap on both axes. I addition wraps to 16 bits without changing VF. Font lookup uses the low nibble.
  • Legacy 0nnn SYS is a no-op. Super-CHIP and XO-CHIP extensions are not supported.
  • Fx0A waits for a fresh press. Timers continue while waiting. Pause freezes timers; step executes one instruction only.

Speed changes the CPU budget, not the 60 Hz clock. Reset reloads the active ROM and pauses. Switching tabs or leaving the window clears held keys and pauses the machine.
