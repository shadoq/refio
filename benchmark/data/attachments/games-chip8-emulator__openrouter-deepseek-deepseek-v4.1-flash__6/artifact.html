        How to use

        1. The built-in demo ROM is loaded on start (paused). Press Run to execute it.
        2. Use Step to advance a single instruction and inspect the debugger.
        3. Adjust Instructions / frame to change emulation speed.
        4. Load your own .ch8 / .rom file with the file picker.
        5. The demo draws a smiley that bounces left/right. Press 5 (W) to move it down, 8 (S) to reverse direction.
        Fully self-contained single file — works offline from file://.
