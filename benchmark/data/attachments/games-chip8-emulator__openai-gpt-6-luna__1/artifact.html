Quick guide

Controls

Run starts execution; Pause freezes it. Use Step to execute one instruction, or reset to restart the current ROM.

Change instructions per frame with the speed slider. Click or hold a keypad button, or use the mapped keyboard keys. Both key press and release are sent to the emulator.

The demo draws a small sprite and waits for a key before moving it across the screen.
