Operator notes & compatibility

Load a binary, then Run. Pause freezes both CPU and timers. Step executes one instruction without ticking timers. Reset reloads the selected ROM and pauses. Speed is instructions per virtual 60 Hz frame, not a claim of hardware cycle accuracy.

  • Modern: shifts use VX; FX55/FX65 leave I unchanged; OR/AND/XOR preserve VF. Original-style: shifts use VY; transfers increment I; logic clears VF.
  • Both modes use BNNN + V0, and subtraction sets VF for no borrow, including equality. I arithmetic wraps at 16 bits. FX29 uses the low hexadecimal digit of VX.
  • Sprite starting coordinates are reduced modulo 64 × 32. Overflow pixels clip unless wrapping is enabled. DXY0 draws zero rows, not a Super-CHIP sprite.
  • FX0A waits at its instruction address for a fresh key press followed by release. Previously held keys do not satisfy it. Timers continue while running and waiting.
  • Classic 0NNN native-machine SYS calls are ignored. No Super-CHIP or XO-CHIP extensions. Invalid classic encodings, invalid memory accesses and stack errors pause the machine.
  • Keyboard and pointer sources are independent. Leaving the window clears held inputs. Background time is discarded; foreground catch-up is capped at 250 ms.
