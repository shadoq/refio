How to play

Press Run to start the built-in demo. Its five-pixel sprite waits for a key, then moves and waits again. Use Q / E / S / 2 or the ← / → / ↑ / ↓ arrows to move left, right, up or down. Any other CHIP-8 key moves right. Hold or tap the on-screen keys on touch devices.

Load a local CHIP-8 ROM to replace the demo. Pause freezes execution and timers; Step executes one instruction while paused; Reset reloads the current ROM. Adjust instructions per frame to change execution speed.
