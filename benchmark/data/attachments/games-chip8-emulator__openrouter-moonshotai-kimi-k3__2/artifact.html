Help

Built-in demo: a diamond sprite is drawn on screen — move it with W (up), A (left), S (down), D (right), which map to CHIP-8 keys 8, 7, 5, 9.
Full keyboard mapping (keyboard → CHIP-8): 1→1 2→2 3→3 4→C Q→4 W→5 E→6 R→D A→7 S→8 D→9 F→E Z→A X→0 C→B V→F. The on-screen keypad buttons are also clickable/touchable.
You can load any CHIP-8 ROM from a local file using the file picker above; it will be loaded at 0x200 and started automatically.
