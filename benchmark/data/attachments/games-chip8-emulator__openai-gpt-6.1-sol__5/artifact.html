A tiny machine. A real interpreter.

The built-in sprite demo is loaded and paused. Press Run, then move with W/A/S/D. The demo is actual embedded CHIP-8 bytecode, not a JavaScript animation.

Load a local binary ROM of 1–3,584 bytes, with any filename or extension. Files never leave your browser. Reset reloads the selected ROM and pauses. Step pauses and executes exactly one opcode without ticking timers.

Keyboard input works outside form fields. Key waits accept a fresh press, even while paused. Switching tabs pauses the machine; losing window focus releases all keys.

Classic CHIP-8 profile

4 KB RAM · programs at 0x200 · 80-byte font at 0x050 · 16 return addresses. Delay and sound timers run at 60 Hz independently of CPU speed, and freeze when paused.

By default, shifts use Vx; logic preserves VF; register transfers leave I unchanged. Bnnn jumps with V0. Sprites wrap on both axes. Fx1E wraps I at 16 bits and preserves VF. The two switches above apply immediately.

Legacy 0nnn SYS is a no-op. Super-CHIP and XO-CHIP extensions are not supported. Invalid opcodes or out-of-bounds fetches, memory accesses and stack operations halt safely with a diagnostic.
