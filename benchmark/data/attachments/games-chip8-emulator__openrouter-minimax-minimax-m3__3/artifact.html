Instruction reference

The full standard CHIP-8 instruction set is implemented: 2 system opcodes, 2 jump opcodes, 2 register-comparison opcodes, 4 skip opcodes, 2 memory/index opcodes, 16 arithmetic and logic opcodes, 1 register-inequality opcode, 1 index-set opcode, 1 jump-offset opcode, 1 random opcode, 1 display opcode, 1 key-test opcode and 10 miscellaneous opcodes. VF carries the carry, borrow and shift flags; FX33 converts Vx to BCD at I; FX55/FX65 move V0–V7 between I and the register file and advance I by X + 1.

Implemented opcodes
  • 00CN clear screen / return
  • 1NNN jump to NNN
  • 2NNN call NNN
  • 3XNN skip if Vx = NN
  • 4XNN skip if Vx ≠ NN
  • 5XY0 skip if Vx = Vy
  • 5XY1 skip if Vx ≠ Vy
  • 5XY2 skip if Vx < Vy
  • 5XY3 skip if Vx > Vy
  • 6XNN Vx = NN
  • 7XNN Vx += NN
  • 8XY0 Vx = Vy
  • 8XY1 Vx |= Vy
  • 8XY2 Vx &= Vy
  • 8XY3 Vx ^= Vy
  • 8XY4 Vx += Vy, VF carry
  • 8XY5 Vx -= Vy, VF borrow
  • 8XY6 Vx <<= 1, VF shift-out
  • 8XY7 Vx >>= 1, VF shift-out
  • 8XY8 Vx = Vy + Vy
  • 8XY9 Vx = Vy + 1
  • 8XYA Vx = Vy × 2
  • 8XYB Vx = Vy − Vx
  • 8XYC Vx = Vy × 2, VF carry
  • 8XYD Vx = Vy − 1
  • 8XYE Vx >>= 1, VF shift-out
  • 8XYF Vx = Vy + 1, VF carry
  • 9XY0 skip if Vx ≠ Vy
  • AXYN I = NNN
  • BXYN jump to NNN + V0
  • CXNN Vx = random & NN
  • DXYN draw XOR sprite
  • EXNN skip if key pressed
  • FX00 no operation
  • FX07 Vx = key currently held (0xFF if none)
  • FX0A sound timer = Vx
  • FX15 Vx = delay timer
  • FX18 Vx = sound timer
  • FX1A Vx = last key or 0xFF
  • FX21 store V0–VF at I
  • FX33 Vx → BCD digits at I
  • FX55 load V0–VF from I
  • FX65 I += Vx
  • FX75 sound timer = Vx
  • FX85 delay timer = Vx

Controls

Keypad

Press and release are tracked FX1A returns the last pressed key

Key mapping

Top row: 1 2 3 C. Second row: 4 5 6 D. Third row: 7 8 9 E. Bottom row: A 0 B F.

Keyboard mappings are 1–4, Q–R, A–F, and Z–V respectively. The demo uses the left keypad to move a sprite and the right keypad to clear it.
